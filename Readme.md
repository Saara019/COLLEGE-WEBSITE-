SCNIP College Website

This project is a college website developed for SCNIP College. The website provides information and services for students, faculty, and visitors through a user-friendly web interface.

https://www.scnip.in/


The project consists of two main parts:

1. Frontend Website
   The frontend is the public-facing website that allows visitors to view college information, announcements, academic details, facilities, and other relevant content.

2. Admin Dashboard
   The admin dashboard is used to manage website content and administrative information. Access to the dashboard is restricted to authorized administrators through a login system.

Features

* Responsive college website interface
* College information and academic details
* User-friendly navigation
* Announcements and important information
* Admin login and access control
* Admin dashboard for managing website content
* Separate frontend and administrative sections
* Clean and simple interface

Technologies Used

* HTML5
* CSS3
* JavaScript
* Node.JS
* MongoDB
* Express
